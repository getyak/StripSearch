2026-10-02，原创林舟 / Lantern 合成样例。这里只记录设计实验的实际检查，不证明真实 Search / Fetch 质量或线上可用性。

## 离线

- `tests.cjs`：19 项通过。覆盖未读内容、JSON/Markdown、范围草稿与保存、读取许可、身份依赖、撤回/恢复、暂停/停止、无授权状态、手机面板与键盘重绘焦点。
- `python3 scripts/check_design.py`：本地链接、12 个基线合成案例、12 个来源、报告引用与原有格式一致性通过；这不是模型或端点评测。
- `git diff --check`：通过。新增 CI 使用仓库已有固定 jsdom 依赖运行原型检查。
- 独立 reviewer 检查并复核：未读 JSON、归属失效后的旧回答、手机返回/追问、固定介绍泄露、覆盖标签和键盘焦点问题均已修正；没有未解决的 P0/P1。

## 实际浏览器

使用 Chromium 内嵌浏览器，通过可见按钮和输入执行。验收过程截图：[桌面出处](screenshots/desktop-source.jpg)、[手机出处](screenshots/mobile-source.jpg)；只包含原创合成材料，不包含参考文件的真实人物研究。

| 路径 | 实际结果 |
| --- | --- |
| 1440 × 900 桌面 | 200 / 784 / 456 三列；各面板高 848，正文独立滚动，整页没有横向溢出 |
| 768 × 1024 | 人物导航与正文保留，对话由按钮打开；页面宽高与视口相同 |
| 375 × 812 | 单列与原生面板；修正高度后页面宽高与视口相同，没有重复聊天输入 |
| 新建输入 | 真实输入显示未连接且未外发；只有明确“林舟”启动合成样例 |
| 账号确认 | X 选择研究后未自动授权；单独勾选后保存范围 v2，旧对话清空 |
| 阅读控制 | 暂停、停止与恢复保持材料；下一批写入回执后仍显示部分完成、历史未知 |
| S2 撤回 | C2/C4 待复核，S1 独立归属和 S3 作者回应仍有效 |
| 再撤回 S1 | S3 正文保留，人物归属待复核；旧作者回应答案显示依赖已变化 |
| 手机作品追问 | 答案面板直接打开，出处可返回对话；无需关闭后重新寻找答案 |
| 手机键盘 | 发送后焦点为 `chat-send` 且仍在面板内；Escape 关闭回到 `mobile-context` |
| 导出 | 实际 Markdown 文件包含撤回与旧回答失效；实际 JSON 文件保留 `synthetic=true`、partial、scopeVersion、revision 和来源/结论 |

浏览器下载事件桥曾超时，但文件确已下载；随后从本机实际文件读回验证，而非把按钮回执当下载成功。后续补入的状态截至时间由共同快照派生，经过离线检查。
