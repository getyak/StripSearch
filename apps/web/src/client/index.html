使用之前

一些值得
说清楚的事。

首页的材料是真实研究吗？+

不是。页面上的材料是原创合成示例，打开引用不会发起研究。只有提交上方输入后，才进入当前部署的真实研究流程。

同名账号会自动合并吗？+

不会。同名候选与身份归属应分别核查；资料关联到一个人，也不代表资料中的每项说法已经得到支持。

没有足够材料时会怎样？+

保留有限发现、冲突和未知。没有材料的时段不会被补写，推测也不能变成已支持的事实。

可以在哪里使用？订阅开放了吗？+

当前提供可自托管的 Web alpha。个人与团队付费订阅尚未开放；第三方工具的实际覆盖、访问与效果需分别验证。

哪些资料可以用于研究？+

用于公开职业作品、采访准备与授权自我研究。普通个人的材料需要明确授权；不提供私人位置追踪、匿名身份揭露或访问控制绕过。
