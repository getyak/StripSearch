# 人物与账号确认工作区

将 Figma [账号选择组件 251:4082](https://www.figma.com/design/0mWx06dWHOz0gCPjjAgcPp/StripSearch?node-id=251-4082) 适配为低噪声的研究工作台。内容节奏参考 Notion，工具层级参考 Linear，iOS 的材料感只用于顶栏与常驻确认栏。人物锚点保持紧凑，桌面账号使用密集双列决策单元，手机使用单列；平台标识和淡水印继续来自设计稿资源。

## 五轮深化

1. 收敛顶栏、历史栏、标题和阶段路径的层级，阶段使用语义名称，不再用装饰性编号。
2. 将人物参照压缩为可持续定位的身份锚点，移除大面积空头像占位；同名候选仍分别选择。
3. 将账号卡从展示海报改为约 216px 起步的决策单元，减少圆角、阴影和间距，补齐 hover、pressed、focus 与非颜色选择反馈。
4. 确认栏成为独立控制层，支持安全区、常驻计数和克制动效；内容卡不使用玻璃或大面积模糊。
5. 修正 390px 确认栏和 320px 工具栏占高，复测桌面、平板、手机横竖屏、暗色、减少动态和键盘返回。

## 行为边界

- 先确认人物，再勾选账号；同名候选保持独立。选择、出处展开、不是此人和仅研究独立账号各自执行原有动作。
- 计数与提交按钮放在滚动内容之外，切换研究或退出确认时清空。刷新保留草稿；新账号不自动加入。
- 用户选择不会升级身份可信度，未确认、反证、范围限制与出处继续显示。提交载荷和服务端研究流程没有变化。
- 没有可信头像字段时使用中性单字标记，不复制设计稿人物照片或简介。没有新增抓取、模型或付费 API 调用。

## 验证（2026-10-12）

- TypeScript、生产构建、1270 项完整测试（1269 通过、1 跳过）与设计检查通过；独立 review 没有未解决的 P0/P1。
- 浏览器使用实际生产构建、原创合成资料和本机内存存储。1440、1024、900、844 横屏、768、390、375、320 宽度均无页面或工作区横向溢出；确认栏贴合视口底部。390px 确认栏从 119px 收敛到 80px，320px 工具栏隐藏无来源可看的入口。
- 检查浅色、暗色、减少动画、账号勾选、计数与按钮启用、证据 Escape 收起并返回焦点。同名与独立账号语义继续由离线 DOM 测试覆盖。
- 同名候选的独立账号提交经过实际选择校验与存储，身份仍未确认；提交后确认栏清空、对话栏恢复。此验收没有执行真实研究，不代表研究质量或外部 provider 已验证。
