# Search：先辨识人物，再核对归属

2026-10-07。本地实现及离线验收完成，真实模型判断质量尚未验收。最新 Figma 节点未读取成功：官方 MCP 返回 Starter 调用额度上限；改用 Figwright 后，本地桥接仍连接其它文件，目标 StripSearch 画布未完成加载，暂未取得目标节点；界面细化沿用已有核验格式，不能称已对齐最新画稿。

Search 在冻结初始召回后，向模型提供候选目录、真实来源目录及剩余额度。Agent 可以选择后续检索、已发现身份页读取、搜索实际返回的机构人物页与本地原文窗口，再提交有出处的归属提议。每次决策与外部工具请求通过原有账本；原文是数据，不能授予新工具、权限或身份。

人物辨识、跨平台关联、材料作者是不同问题。机构人物页可以帮助辨识人物；机构首页、组织账号和项目成果不能因此成为本人账号或个人贡献。本人关联仍须通过现有目标绑定、可见文字、原文回执和当前依赖核验。自报确信度不成为证据，同源材料不重复计作独立支撑。明确反证阻止默认建议。未核归属的主页标记为未评估来源；机构人物页按 origin 分组，不能将多页重复计作独立来源。

工具读取仅用于身份发现；正文、历史和评论继续等用户确认范围。窗口控制单轮上下文，不裁掉存储原文；来源目录不限于前八篇，Agent 可定位后续窗口。未知请求结局、取消、作用域变更和额度耗尽保留真实缺口，不伪造完成或自动重试。

选择页保留一次范围确认。账号标识只显示一次，研究价值用一句话；原文、反证、归属判断和回执按需展开。组织与第三方资料进入独立区域，归属不明仍可显式单独研究，不能合成人物结论。

机构读取目前只覆盖搜索真实返回、标题匹配姓名的 `/people/name`、`/faculty/name`、`/staff/name`、`/team/name`、`/researchers/name`、`/biography/name`、`/bio/name` 路径。服务端重查同一尝试的成功搜索回执；页面保留为第三方辨识资料，不能升级为本人账号、组织主页权限或个人贡献。此路径目录不代表机构信誉认证，也未覆盖所有机构网站。

组织类型只采用与实际请求、原生 ID、返回地址和原文哈希绑定的 GitHub 原生响应，同时约束请求与返回两个账号键。后续失败、缺失类型或地址大小写变化不抹掉已知组织标记。当前选择、旧证据投影和 Fetch 都重新检查这些依赖；历史原文和回执保持不变。首次 IO 前持久冻结 Agent 策略，旧尝试不因代码更新新增模型调用。

验收使用合成资料和离线适配器：437 项受影响的 Search、身份语义、选择/恢复、工具与控制器测试全部通过；TypeScript typecheck；客户端构建；`python3 scripts/check_design.py`。真实 Chrome 中检查桌面、390px、320px 与暗色组件，验证勾选、组织独立范围、证据展开及无横向溢出。独立 reviewer 已关闭所有确认的 P0/P1。
