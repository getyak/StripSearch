# 官网连续研究叙事

2026-10-06：替代首页独立的四步播放卡片。当前是本地 Web alpha 的官网实现；合成场景不证明托管服务、全平台覆盖或研究质量已验收。

## 设计选择

访问者带着公开用户名或主页准备采访、理解作品，需要先确定材料属于谁，再判断材料能支持什么。采用「连续研究桌」：一份右侧工作区随阅读展开。备选「逐页档案」把材料拼成资料墙，再进入时间切片；保留探索，但身份关系与第三阶段侧栏不够直接。

参考 [Notion](https://www.notion.com/) 的白底、明确标题与产品画面，[搜索页](https://www.notion.com/product/enterprise-search) 的引文邻近来源，以及 [Linear](https://linear.app/) 的连续工作区；不使用第三方插画、客户标志或产品承诺。白色、近黑文字、森林绿强调；系统深色有等价对比。系统字体、无远程字体请求。

## 三个阶段

| 阅读阶段 | 右侧工作区 | 事实边界 |
| --- | --- | --- |
| 输入 | 合成用户名林舟与研究问题 | 线索不是身份结论；真实输入始终可提交 |
| 身份关系 | 项目主页关联 Lantern，独立同名候选待确认 | 仅为合成关系；真实研究的身份确认仍由运行时控制 |
| 证据与理解 | 报告展开，出处检查器从右侧进入 | [S1] 2025 年 6 月更新记录宣布新增离线阅读与本地索引；不能证明个人独立贡献或实际使用效果 |

桌面 CSS sticky 保留一个工作区外壳；IntersectionObserver 选择当前阅读章节，不用计时播放、滚动劫持、假进度或常驻动画循环。向上阅读可回到前阶段。用户正在出处详情内操作时保持该阶段与焦点，离开后同步阅读位置。

手机、短视口、减少动态效果、无 IntersectionObserver 或无 JS 时，各阶段按原始 DOM 顺序显示在对应章节中，无空白长段落或被隐藏的结果。动态媒体设置和路由离开/返回会清理并重新建立必要观察器；dispose 清理全部监听器。

演示标明「原创合成示例 · 非实时研究」，无请求、无供应商调用、无自动提交。源码、真实表单、清空、校验、认证与 Cmd/Ctrl+Enter 契约保持有效。锚点 `#example` / `#pricing` / `#boundaries` 不发起研究；`#/app` / `#/review` 保留实际路由。原生 details 支持键盘核查，滚动不关闭用户已展开的内容；阶段变化不作为 live region 播报。
