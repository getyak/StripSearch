正常构建并启动本地 Web 服务后，使用 `apps/web/scripts/check-home-ui.mjs`。设置 `CHROMIUM_EXECUTABLE_PATH` 指向已安装的 Chrome/Chromium，再传入 loopback URL 与本次证据目录。脚本拒绝非 loopback 目标，拦截外部访问和所有 API 写入，不提交账号或真实研究。
