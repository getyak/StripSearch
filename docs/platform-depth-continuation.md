# 跨平台持续研究：取消固定总量上限

2026-10-02，GET-132。用户要求以授权公开账号完成跨平台深读，不接受 24 页、固定总请求/模型轮数/总时长成为研究范围。本指令取代上一轮深度契约的固定容量和默认总量限制。

新研究默认不设页面、总工具调用、模型轮数、总 token 或累计时长的硬上限。配置值 0 明确表示该维度未设固定总上限；显式正整数限制仅用于用户或部署自行选择的批次，旧 checkpoint 的已冻结限制不悄悄重写。保留取消、来源撤回、公开 URL 校验、单次请求超时/正文读取回执、未知扣费禁止盲重试，分批传输不等于缩减整体范围。

所有返回页面和正文保存在同一 corpus，不再因页面 ordinal、24 页或单条字数而静默丢弃；模型上下文按窗口选取，明确当前展示片段与其余已存正文。不能把模型上下文窗口当全文读取范围，也不能因五个问题已有断言而称所有平台研究完成。未回读线索、截断、分页/互动缺失和不可访问均保留为可继续的缺口。

来源和平台的发现、正文、作者回应、历史与独立核验分别计算；同站翻译/转载不充当独立佐证。没有可读原文、媒体或讨论的真实平台不得虚报深度完成。未知平台、改名/旧账号和新发现的自链继续进入待核对队列，不局限于预设几家平台。线上供应商能力仍需逐端点实测，取消应用限制不能越过平台实际访问边界。

验收：超过 24 页仍保留并能继续读取；未设固定总上限时越过旧 12/8 调用阈值仍运行、仍可取消；显式限制和历史账本不回退；大正文原始 corpus 不丢失、模型片段显式；有未读线索不能伪报全研究完成；原文、依赖、撤回、成本和四种导出保持一致。所有公开回归使用原创合成数据，真人资料只存授权私有工作区。

实现窗口：catalog 的 offset / linkOffset / unknownOffset 选择本次模型看到的目录切片，inspect 的 sourceKey / offset 选择活跃来源原文；两者只保存选择器，旧 inspect 文本缓存不受信任。超过 Node 单定时器范围的显式累计时长分段计时。供应商读取、SSRF、每次 HTTP 字节/超时和模型单输出约束继续保留，不冒充全平台覆盖。
