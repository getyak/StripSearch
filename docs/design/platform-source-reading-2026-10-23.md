# 来源平台阅读细化（2026-10-23）

本轮在既有 canonical 报告上做保守的来源平台阅读体验：来源行与来源详情增加安静的平台 / 域名 / 状态上下文，出处面板增加基于真实来源的平台覆盖摘要，历史列表压缩 URL 预览。呈现层改动，不新增事实、不改变来源、证据、归属、撤回与引用返回契约。能力边界仍以 [Web 运行时契约](../web-runtime.md) 为准；视觉基线沿用 [2026-10-21「循证阅读」](../web-design.md)。实现与离线验证记录见 [Web 设计](../web-design.md) 对应章节。

## 共享投影契约（`apps/web/src/shared/source-presentation.ts`）

纯函数投影，输入是来源上已观察到的字段（URL、来源类型、获取状态），输出只用于展示。不写库、不发请求、不含事实推断。旧 canonical 报告无需迁移：投影按需派生，缺少或未知字段安全回退。

1. **平台标签只按链接主机推断。** 已知主机表覆盖 GitHub、X（Twitter）、Bluesky、Threads、Reddit、YouTube、Bilibili、小红书、抖音、TikTok、Instagram、Facebook、知乎、微信公众平台；其余一律回退「网站」。匹配只允许主机名精确等于已知域名或其子域（`host === 域名 || host.endsWith('.' + 域名)`）。
2. **拒绝混淆后缀主机与不安全链接。** `github.com.evil.example`、`fakegithub.com`、`x.com.malicious.example` 之类混淆后缀主机不匹配任何平台，回退「网站」并照常显示真实域名。非 http(s) 协议、无法解析、空主机、单标签主机（无点，非公开域名）或带内嵌凭据的链接不生成可点击链接，只按原文展示并记录限制。
3. **平台标签不是证明。** 每次匹配都附带限制文字：平台标签不是身份归属、能力支持或已读完的证明。不编造作者、数据指标、缩略图、头像、媒体内容、认证标识、阅读完整性或平台支持声明。
4. **内容形态只来自观察到的 URL 形状或来源类型。** 例如 YouTube / Bilibili / 抖音 / TikTok 的视频**页面**只标注「视频页面」并注明媒体（图片、音视频）未读取、不代表已观看；账号页形状只标注「账号页面」并注明归属未确认。形状不明时留空，不猜。
5. **取得材料只看获取状态。** 只有 `fetchStatus: 'ok'` 才说「已取得材料」，且永远附带「不代表该来源或平台的全部历史已读完」；`truncated` / `inaccessible` / 未知状态分别如实说明，不把摘录冒充完整原文。

## 来源行与来源详情

- 来源行在标题下以安静小字显示：平台 · 域名 · 来源类型 · 发表时间 · 状态（已排除优先显示）。行内不放头像、缩略图、favicon 或任何第三方资源。
- 来源详情补充「平台 / 域名 / 内容形态」元数据行与材料状态说明；摘录用更强的可读排版（更大字号、行距、正文色），原始文本披露保留。次级元数据（发表/获取时间、身份归属、状态）与已知限制保持可见，展示限制与来源自带限制合并列出。
- 链接行只在安全 http(s) 地址上生成 `target="_blank" rel="noopener noreferrer"` 锚点；不安全链接降级为纯文本。
- 不引入任何第三方网络请求、iframe、favicon 或远程资源加载；全部渲染离线。

## 来源平台覆盖摘要

出处面板顶部给出基于**本次运行真实来源**的紧凑覆盖摘要：按平台分组的来源条数与已取得材料条数。它与第一步的「已选 / 已发现平台」无关，也不随当前来源筛选变化；固定附注：只统计已有来源，未列出的平台不代表被搜索过，任何平台都不代表全部历史已读完。

## 历史预览 URL 压缩

历史列表的问题预览把内嵌 URL 压缩为「主机 + 短路径」（去掉查询与片段、逐段安全解码百分号编码、超长截断），URL 后的散文照常显示，不再出现巨大的百分号编码路径。完整问题始终保留在 `aria-label` 与 `title`，可访问名称不变。

## 渲染与可访问性

沿用纸白 `#f3f1e9` / 森林绿 `#2d5241` 既有 token；触控目标不小于 44px；来源列表键盘漫游、分页与引用返回焦点在重渲染和筛选后保持精确；窄屏、深色与减少动效沿用现有派生，不新增动效。
