# 多平台研究的状态与来源契约

2026-10-23。本轮保持已冻结账号范围、身份归属、canonical 报告与来源撤回规则。

- 网站分类器内部以域名作为 handle，不构成社媒账号。人物候选只能将真实账号 handle 加 `@`；个人网站回退到公开入口，来源支持的姓名仍优先。
- 知乎、豆瓣已支持的公开域别名归一到各自受控规范域，重分类必须幂等。相似域和原始双 `www` 不升级为真实平台账号；旧持久化快照不批量改写。
- 账号选择页的可读状态表示主页资料可用，不表示帖子、视频、转写、评论或完整历史已取得。选择不升级账号归属。
- 逐个所选账号读取后立即发布已保存的真实来源。失败先保存检查点，再发布该账号的 unavailable 事件；不制造成功、不静默重放失败或未知请求。
- 研究中的读取与核验缺口来自 canonical `research.unresolved`，持续可见；终态同时保留。历史核对项保留原限定，不升级为当前平台失败。已取得材料与失败账号并存。
- 供应商公开错误码可以翻译为用户能理解的原因，目标 URL、未知、原有限定和回执保持不变。计费/额度受限不能通过普通重试按钮被当作已解决。
- 非活动研究、登出和账号切换会清空保留容器中的缺口文字与展开状态，隐藏容器不保留上一账号的内容。
- 供应商忽略取消并迟到返回时，实际请求费用仍结算；取消状态在检查点与来源写入前重新检查，迟到材料不得发布。

实际效果仍需独立审查、真实浏览器与供应商回执验收。本契约不声明新平台原生接入或完整历史覆盖。
