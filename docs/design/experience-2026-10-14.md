# 证据阅览室 · 官网与 Web 体验改版

状态：官网与现有 Web 界面已实现，已完成离线与合成浏览器验收。仅改善既有 Web alpha，不新增 provider 能力或质量承诺。

## 产品不变量

访问者为准备采访、阅读公开作品的研究者。紧张点在于：名字相同是否同一个人，资料是否足以支持判断。进入页面后应理解“姓名或主页 → 确认身份 → 阅读有出处且保留未知的报告”，能立即提交线索。产品区别落在身份归属、事实支持与分析分列，以及来源撤回后的依赖复核；不声称竞品没有这些能力。

当前实现的优点：中文任务明确、真实表单直接可达、原创合成材料有标注、引用可展开。问题：三段相同的左右布局，首屏的种子表单重复真实输入，工作台高饱和色和重边框竞争注意力。

## 方向树与选择

- D1-A「证据阅览室」：理解是一份可打开核查的材料。空间为输入与报告书页并置，优先展示证据和未知；识别交互为点击引用展开原文。避免普通 SaaS 功能卡与装饰书斋。
- D1-B「线索标本台」：从一个线索连接独立材料。空间为中央输入与周边线索，优先展示探索；识别交互为线索归属选择。避免监控大屏与无依据关系网。
- D2-A1（胜出）：首屏直接输入和证据物 → 横向身份关系 → 宽幅结论/来源对照 → 简洁方法 → 版本与费用边界 → FAQ。首屏立即展示输出，后续切换布局节奏。
- D2-A2（保留挑战）：中央输入 → 材料对象聚集 → 展开阅读。首屏留白和记忆点更强，证据的阅读位置更低。
- D3：[可运行 A/B 原型](../../design/explorations/evidence-reading-2026-10-14/index.html)，相同合成内容、1440×900 与 390×844 比较，包含一段后续证明区。原型不是运行产品。

相对判断 A 对 B（-2 到 +2）：辨识度 +1（证据条与未知同框）；产品真实 +2（首屏已有来源与限制）；理解 +1（输入与结果同时可见）；结构 0；情绪 +1（静态阅读更符合核查）；实施 +1；可访问性风险 +1（无需周边物件定位）。这是设计判断，未做真实用户偏好实验。

若新首页仍只有左侧说明加右侧表单，或证据只能滚动后看到，应回退重构。B 原型保留，不能把改配色当另一个方向。

## 视觉系统

采用项目现有原生 TypeScript/CSS，以自有审美语言实现，不引入新 UI 框架或商业字体。Design dials：variance 7 / motion 3 / density 4（工作台 density 7）。

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| 环境 | 暖纸 `#F3F1E9` | 墨绿 `#151D19` |
| 阅读面 | `#FFFEF8` | `#1C2721` |
| 次级面 | `#E8EDE2` | `#25332B` |
| 正文 | `#243A31` | `#E7EDE5` |
| 辅助正文 | `#58675E` | `#B4C2B7` |
| 操作 | `#2D5241`，白字 | `#A9CFB3`，深墨字 |
| 未知 | 琥珀文字与文字标签 | 同语义高对比变体 |

颜色只是起点，实际配对必须测量对比。系统中文 sans 用于界面和主标题；宋体仅可用于首页原文引用，不用于操作、账号或数据表。主标题桌面约 56–64px、手机 34–38px，真实输入和主按钮必须在 390×844 首屏可见。元数据不低于 12px，正文通常 15–17px。

形状：操作 8px，输入/对话框 12–16px，材料页 4–8px。只让主材料物带轻微分层纸张和接地阴影，其余依靠空间、语义底色与分隔。保留品牌文字及现有导航名称、路由、表单 ID 与账号行为。

## 界面与状态

- 官网：首屏真实输入，右侧原创合成 Lantern 更新材料，有支持的内容、来源、日期与未知同时可见。输入示例不自动请求；点击引用才打开对应材料。身份段明确同名不合并；方法与价格保持诚实边界。移动端独立重排，禁止桌面整体缩小。
- 工作台：历史环境、主阅读面与按需出处面板分层。报告长文本、引用、来源排除、恢复与受影响结论保留既有语义；信息不可因样式被隐藏。新建、检索、取消、导出、历史与出处在窄屏仍可达。
- 人物与账号确认：保留当前单选人物、明确账号选择、草稿、冲突与固定提交区；选中、待确认、被排除均有文字标签。
- 登录：系统 native dialog、显示标签、清楚错误、可见焦点、Escape 关闭和焦点回到触发处。注册默认开放的服务策略不变。
- Fetch 与标注：采用共同环境/表单/列表/空状态语言；保留显式授权、真实请求状态、缺口、待核与评审语义。不得以样式将未验证状态变成成功。

## 动效契约

品牌动作只有“引用连接原文”：显式打开后 180–220ms 的颜色/透明度强调，提供空间关系；无持续循环、滚动劫持或假进度。静态显示完整内容，取消旧的长距离自动换页/搬移 DOM 叙事。按钮、输入反馈 120–180ms；减少动效下立即完成反馈且内容不丢失。生命周期必须移除监听与取消未完成动作。

## 验收边界

功能检查与设计判断分开。自动检查不证明品味领先；没有真实用户对照或性能 trace 时，不宣布“超过 Ambi”、转化提升或稳定帧率。验收覆盖桌面/平板/窄屏、浅深主题、减少动效、引用展开、身份选择、长内容、空/错/忙/有限结果、键盘与原有离线测试。全程不调用付费模型或 provider，不读取示例域名。

## 实施记录（2026-10-15，本地实现与验证）

已按 D2-A1 在 `apps/web/src/client` 落地：首屏真实表单与 Lantern 合成材料同框（支持语句、来源与日期、显式未知）；身份段改为横向关系轨道；证据段改为宽幅结论/来源对照（serif 仅用于原文引文）；方法、版本与费用边界、FAQ 各自换布局族，不再是左文右卡重复。旧滚动叙事与面板 DOM 搬移已移除，`createHomeMotion` 接口保留为显式引用揭示（就地打开材料、焦点移到披露行、200ms 颜色/透明度强调），无 JS/减少动效下全部内容可读，无计时器与网络。共享样式重组为分节 token/组件体系（纸面/墨色/安静绿，营销密度 4、工作台密度 7），auth/历史/报告/出处/人物确认/Fetch/标注共用同一 token；路由、导航名称、表单 ID、认证与注册策略、API 与事实/不确定性语义未改。

对比度按 WCAG 相对亮度实测（静态配对）：浅色正文/纸面 12.05、辅助/环境 5.28、操作白字/操作底 8.77、未知/纸面 5.51；深色正文/阅读面 12.96、辅助/次级面 7.15、操作深墨/操作底 9.27、未知/次级面 6.41；控件边框对承载面 ≥3:1。完整配对表见[Web 设计](../web-design.md#当前基线证据阅览室2026-10-14)。

最终离线验证：`typecheck` 与客户端/服务端构建通过；全套 Web 测试 **1409 通过、0 失败、1 跳过**（维护者上游字节审计缺少 `PUBLIC_RULE_SOURCE_DIR`，没有将其计为通过）。冻结 provider 用例 40/40、合成对抗契约 33/33 通过，模型与网络调用均为 0；数据集完整性、`check_design.py` 通过。最后的 CSS 状态/对比修复之后补跑客户端构建与受影响的 12 项行为测试通过；远端 CI 以最终提交再执行完整门禁。

Codex 浏览器复核了 1440×900、850×900、390×844、320×740，包含访客与已登录导航、浅深色、减少动效、引用展开与可见焦点、登录空值错误、人物已选/同名未选、报告出处检查/排除/撤销/返回、Fetch 空值与范围说明、合成案例审阅。所有浏览器状态均使用原创合成材料，没有触发外部 provider。桌面第一个引用从约 1718px 提前到 493px；390px 从约 2666px 提前到 709px，主按钮底部约 493px。测量属于特定视口的布局事实，不能推导转化或研究质量提升。

复审确认并关闭：801–940px 导航缺口、日期排版变化后的测试断言、同名未选状态遗失的全宽布局、浅色小字/占位字对比不足；另在浏览器中修复登录按钮被 flex basis 拉成 180px、引用焦点落在视口外。独立 reviewer 最终无未解决的确认问题。验收截图、测量与检查范围见[验证记录](../../design/explorations/evidence-reading-2026-10-14/VALIDATION.md)。

未做真实用户偏好实验、性能 trace、外部 provider 或公网生产验收；仓库当前没有独立原生客户端，本轮覆盖官网及现有桌面/移动 Web，不宣称原生端或客观品味超过 Ambi。
