# 同一份材料，逐步读深

2026-10-21 首页细化；实现、独立代码审查与本地离线/浏览器验收完成。

## 产品与方向

访问者已有姓名或主页，需要先确认资料归属，再判断材料究竟支持什么。首屏应使其能直接输入；材料演示应明确表达“结论有来处，未知留原位”。原创合成林舟 / Lantern 更新记录贯穿页面，不制造新事实或贡献归属。

延续已有方向树 A「证据阅览室」，保留 B「线索标本台」为挑战方案，见[既有 A/B](../../design/explorations/evidence-reading-2026-10-14/index.html)。本轮另制作桌面/手机构图草图：A 为 55:45 输入与发现并置 → 原文 → 边界 → 身份补充；B 为中央输入 → 下置完整材料 → 原文与边界。选择 A，理由是输入更宽且首屏同时看见具体发现，同一条材料能连续展开，减少重复说明；属于设计判断，不是用户实验结果。没有重新选择品牌，不把配色变化当作新方向。

## 实施与验证

首页现在按 55:45 并置完整研究输入和合成材料，标题统一墨色；输入、示例、提交、快捷键和保存说明收在一处。报告纸突出林舟、Lantern、日期与支持语句。后续先读同一段更新原文，再列事实、未知和解释；身份互链另行核对。价格区只保留一张当前版本卡，未来个人/团队订阅为两行原生披露。

出处括号构成新的简洁品牌标识，并延伸到引用与选中状态。首屏入场约 360–580ms，纸缘光影为一次 18 秒的有限变化；用户可暂停，页面隐藏/离开首页及系统减少动效时停止。后续正文不做滚动入场。hover 与 focus 只强调同组材料关系；原生披露不依赖 JavaScript，增强返回按钮仅在有有效阅读位置时显示。

- 独立 reviewer 逐行检查引用控制器及最后整合的 HTML/CSS/验收脚本，未确认 P0–P3 问题；额外复核原生异步 toggle、关闭后重开与生命周期切换。
