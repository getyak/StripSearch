# 账号比较工作台 · 第一步范围确认（2026-10-21）

状态：实现与离线验收完成，独立审查及交付仍需通过。本文记录交互契约与验证边界；服务端身份与范围授权保持现有契约。

## 要解决的问题

近 2000px 宽屏下旧版只有两张完整候选卡可见：人物参照侧栏与装饰性账号卡占据大量空间；页面标题被当作人名展示；网址重复出现；通用研究摘要掩盖账号差异；人物选择、读取范围选择与身份依据互相竞争注意力。这是一步研究决策工具，不是营销页。

## 布局契约（比较工作台）

- 纸白与墨色主题 token 不变；正文 15–17px、元数据 ≥12px。桌面宽度放宽到 `min(1400px, 100%)`，行式比较而不是卡片墙。
- **目标人物摘要在账号列表之上**，一行紧凑横向：人物标签、标签来源说明、锚点主机、归属链接状态、冲突、短摘录与来源、"已选择为目标"。大头像、水印与厚重边框全部移除；平台图标只保留 18px 行内图标。
- **人物摘要就是所选候选卡**（`article.first-step-candidate` 的紧凑变体）：辨识依据与出处仍是同一张卡里的原生 `details`，可检视原文摘录与原始标记。竞争人物在显式「更换目标人物」披露里（默认收起；未选择目标时默认展开），同名候选永不合并，数量与未合并状态在触发行上可见。
- **账号行是固定五列**：账号 / 能了解什么 / 归属依据 / 状态 / 选择。列头只在桌面显示；按账号列表的实际容器宽度切换：不足 1031px 时按列标签纵向堆叠，侧栏占用空间也计入。行与行之间只有细分隔线，无卡片阴影或水印。
- **行内披露在自己的行下展开**：`details` 打开时横跨整行宽度，收起时触发器回到行右上角的保留区。第一次展开即显示一条有出处的可读原文摘录；完整标题、URL、上下文、反证与限制在进一步披露内保留。原始摘录（含标记）逐字保留，永不执行。

## 呈现契约（安全分列，不造人名）

- 查询/人物标签、账号 handle、站点主机、字面页面标题分列展示，互不冒充：
  - 人物标签优先取**有出处且当前有效**的 `ownerAnchor.personLabel`（自述姓名 / 有独立支持），并在旁边如实标注其来源性质；
  - 没有有效姓名依据时，如实标注为「按查询称呼」「按账号 handle 称呼」或「按公开入口称呼」，绝不把页面标题启发式地裁剪成姓名；
  - 页面标题（例如 `Lin Zhou | Synthetic University`）按原文完整展示并标注「页面标题」，完整原文与 URL 只在证据披露内展开。
- 行的「能了解什么」列按账号特异性排序：原生 ID 冲突 / 依据失效 > 冲突 > 反证 > 归属线索（`attribution.reason`）> 通用 `researchSummary`。任何引文摘录都来自既有返回字段，精确原文保持可检视。
- 选择语义只解释一次（列表顶部）：**勾选只决定本轮读取范围，不代表归属已确认**；未确认、冲突或他人分组的账号只能以独立账号范围研究，勾选不并入人物结论。来源/身份状态与选中状态分列显示，互不转换。

## 行为契约（全部保留的语义）

- 单选目标人物；换人物只移除不属于新分组的人物范围选择并如实提示，独立账号范围保留。
- 一次原子范围提交（expectedRunRevision / expectedScopeVersion / discoveryRevision / 幂等键绑定载荷）；五个选择 facet、独立范围、显式「不是此人」排除与撤销、撤销不等于选择，全部不变。
- 草稿（勾选、独立范围、排除、补线索）跨 SSE 与刷新保留；后到的新账号永不自动勾选；零选择禁用并解释；隐藏的已选账号仍计入提交计数与载荷。
- 已撤回/失效/冲突/组织账号的状态分列显示；组织与第三方保持折叠独立区；同名公开主页、主页外链发现的账号保持独立、默认不选、勾选只授独立范围。
- Escape 关闭行内披露并把焦点还给触发点；焦点、文本编辑范围与滚动位置跨重绘恢复，中文组合输入完成前不重绘；HTML 转义与安全链接不变；owner/session 隔离与 legacy 视图不变。
- 提交后只读：勾选框禁用、排除/独立范围按钮消失、显示「范围已提交」；点击行空白也不能改变已冻结草稿。

## 筛选与搜索（呈现层，不改范围）

- 新增四个筛选 facet：全部 / 已选 / 待核对 / 依据失效，以及按平台、handle、主机的搜索框。两者只作用于当前展示的候选范围，逐行隐藏不匹配项并保留全部 DOM 与草稿；空结果显示解释文案。
- 筛选与搜索永不合并人物、永不修改草稿或提交载荷，selectedCount 与幂等意图不受影响。判定规则：「已选」= 草稿勾选且未排除；「待核对」= 归属未干净落定（非 supported、有反证/冲突/原生 ID 冲突、姓名归属未核对或有争议）；「依据失效」= 当前依赖依据 review、依据被撤回或姓名归属依据 review。

## 验证边界

勾选、筛选和新结果重绘必须保留显式收起的状态；仅记录打开项会把收起误判为首次访问。条目正文用于阅读与复制，只有勾选控件改变选择。查看资料与更多操作分别触发，均支持 Escape 返回触发控件；排除与独立范围语义保持原有契约。
