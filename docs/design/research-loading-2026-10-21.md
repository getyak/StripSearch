# 加载与研究中体验契约（2026-10-21，GET-214）

状态：已实现的客户端呈现契约。目标是把研究进行中的重复标题、状态横幅、活动外壳和几乎为空的报告 / 追问栏，收敛成**一个专注的实时研究面**：输入只出现一次、显示当前实际动作、简短上下文，以及可展开查看的真实过程 / 来源活动。视觉沿用 [Web 设计](../web-design.md)的纸白 / 墨色 / 安静绿体系；能力边界仍以 [Web 运行时契约](../web-runtime.md)为准。本页不宣称未经测量的性能、用户偏好或真实 provider 质量。

## 共享呈现契约

`apps/web/src/client/research-loading.ts` 是唯一推导来源：`deriveResearchLoading({ run, stages, streamState })` 纯函数从实际 `CanonicalView`、实际观测到的 `StageView[]` 事件与真实 SSE 连接状态推导模型，新到达的 active 阶段事件优先更新当前动作，未收到 active 事件时回退到快照阶段；canonical 等待决定或终态始终覆盖旧活动。`createResearchLoadingSurface` 只负责把模型渲染进 `work-body` 中插入一次的 `#research-live` 区块（位于旧 `#run-status-summary` 之前）。它不是新的权威或 API：来源、结论、阶段与状态仍以 canonical 报告和事件流为准。

模型字段：`mode`（`active` / `needs_input` / `stopped` / `none`）、`busy`、`compact`（已有可读内容）、`query`、`heading`（当前动作）、`context`（真实计数与连接说明）、`steps`（语义 `current` / `upcoming` 路径）、`materials`（实际收到且未被排除的来源）、`process`（真实阶段事件记录）。

## 组合规则

- **活跃**（仅 canonical `queued` / `researching`）：实时研究面显示查询一次、当前动作标题、简短上下文、克制的当前 / 待开始路径、实际收到的材料与可展开的「实际过程记录」。旧的请求 / 状态 / 活动外壳、空报告壳与禁用追问栏全部隐藏。
- **进行中有内容**：观察、报告正文或独立账号原文到达后，状态区缩小并隐藏未来步骤路径，标题与状态由实时研究面承担（`renderReport` 在非终态不再渲染报告头），同一输入仍只出现一次。
- **needs_input**：加载面立即退出忙碌（`busy: false`，`#run-indicator` 隐藏），旧的 active 阶段事件只显示为「过程记录」，人物 / 范围决定交给既有 GET-213 人物确认与 GET-210 账号对照工作区（`#first-step-panel` / `#needs-input-panel`），`work-body` 带 `awaiting-decision` 标记强化决定区。
- **终态**（`completed` / `partial` / `failed` / `cancelled`、interrupted）：退出加载面；canonical 报告、`#run-status-summary` 的真实停止原因、保留材料说明与既有手动恢复动作（更多菜单里的重试、新建研究、取消）承担收尾。空的失败 / 部分 / 取消 / 中断结果保留既有「已保留 N 个来源」与限制说明。
- **追问 / 导出**：追问栏与预设只在报告真正支持时出现（终态且有结论，或已有对话）；完整报告、复制、四种导出与追问行为保持不变。

## 诚实边界

- 路径只有 `当前` / `待开始` 语义标签；分母未知，因此不出现百分比、步骤比例、假进度条或耗时里程碑。
- 不因阶段推进就把更早阶段标为「已完成」；完成只来自真实事件本身。
- 来源预览稳定保留前六条，追加资料不会把正在阅读的来源移出预览，其余可从出处面板查看。来源计数只统计实际收到且未排除的记录；只有读取状态为 `ok` 才计入「已读取」，其余保留各自未读、截断或未知状态；计数为零时只说「找到的资料会逐步出现在这里」，不宣称「没有读到任何资料」（第一步概览是另一个权威）。
- 不合成事件、来源、结论或成功状态；未知停止码使用通用真实回退文案。
- 不确定的付费请求结果（如 `outcome_unknown`）绝不自动重试；重试只经既有幂等 API 手动触发。

## 生命周期与交互保持

取消入口在活跃期始终可达（工具栏「取消」）。登出、会话过期、切换研究、SSE 断线重连、快照刷新与迟到响应沿用既有 owner / run 隔离与 epoch 校验；退出加载面时清空该容器的旧查询、来源与过程 DOM，避免登出后只隐藏旧内容；重连与重新打开都会更新连接说明，已收到内容不丢失。渲染就地更新 `#research-live`（保留过程披露展开状态与面内焦点），不搬移滚动位置、不丢草稿、不抢焦点；来源按钮走既有出处检查行为。

## 可访问性与动效

信息不依赖动画传达：路径、状态与计数都是文字。`role="status"` 只覆盖当前动作与上下文行；键盘焦点可见，触控目标 ≥44px；浅深主题同一套 token；`prefers-reduced-motion` 下无信息丢失（本区块不使用动画）。
