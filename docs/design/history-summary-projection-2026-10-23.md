# 历史摘要与实时证据状态

历史列表只返回研究状态、来源总数和待复核数量。原实现为每条历史重新构造完整报告，读取全部来源正文和检查点；单条较大的报告即可阻塞同一服务的健康检查及其它研究请求。逐条让出执行不能中断单条报告内部的同步读取。

摘要现在复用 canonical 的范围、人物归属、引文和账号报告判定，仅读取结论、观察、原文核验和锚点实际需要的来源及其依赖。来源总数来自独立 `COUNT`，没有把未读取的来源数当作零。完整 X 成稿仅需检查当前发表候选；未完成成稿仍保留原有候选选择规则。摘要不返回这一内部裁剪后的报告。

检查点、来源和范围结果只在一次同步摘要调用内部复用，调用结束即释放；没有 TTL 或跨请求状态缓存。撤回、恢复、祖先授权和范围变化必须在下一次读取生效。继承来源还须与父来源当前 URL 和原文一致，单纯沿用 source key 不能继续授权已被替换的旧文。

离线回归把摘要与完整 canonical 的状态、来源总数、待复核数对照，覆盖撤回恢复、祖先变更、范围变化、不安全引文与 X 发表证据。查询守卫拒绝摘要无范围读取全部来源正文，采用确定性读取边界，不以固定毫秒阈值作为正确性门槛。

本机暂停期间只保存实现检查点；定向测试与类型检查尚待恢复后执行。真实浏览器、全套测试和部署验收另行记录，不由本设计文档推定通过。
