# 阅读、核查与继续

GET-132 的本轮界面合同。研究能力、身份关联、证据、分析与未知继续使用既有共享数据合同；界面重排不得增加事实或宣称覆盖所有平台。

## 定位与方向

访客从一个名字或公开主页进入；困难是判断某句话依据什么、核查后如何继续，而不是获取装饰性的“人物分数”。首屏应让人理解输入、报告与出处的关系，感到清晰、可核查，并能立即开始输入。登录、研究限制、错误恢复与合成演示标记必须保留。

可见 A/B 位于 `design/explorations/experience-polish-2026-10-02/directions.html`，参数 `direction=a|b`。A 是阅读桌：结论与出处并置，纸面、留白、细线形成层级；B 是人物时间线：发生顺序组织公开行动，缺失时段留空。桌面和 390px 手机均已检查首屏和中段。A 的出处距结论更近；B 在少量材料时重复时间信息，手机还要经过额外时间线才看到结论。本轮选择 A；B 保留作为明确备选，不把时间线作为默认结构。

相对比较使用 -2 至 +2（A 相对 B），仅用于本项目选型：辨识度 +1（25%），产品真实性 +1（25%），清晰度 +2（15%），结构 +1（15%），情感 +0（10%），可实施性 +1（5%），可访问性 +0（5%）。这是设计判断，不是用户研究成绩或竞品质量评分。

## 体验合同

1. 官网采用 A 的纸面与森林绿体系：优先输入和可操作的证据演示，减少容器叠套、重边框和全屏网格；保留原始合成材料及其未知，不增加图像、虚构统计或运行能力。四步演示的默认结果、手动播放、暂停、跳过、后台暂停和减少动态效果语义继续有效。点击出处是核心交互。
2. 工作区围绕阅读：标题和运行状态保持可见；常用的新研究、检索/导航、出处入口清晰；低频导出、重试和删除收拢至可访问的操作区，活动任务取消不能藏到难以发现的位置。移动端避免横向溢出和工具条多行挤压；阅读正文保留合适行宽与行距。
3. 增加原生 dialog 检索/导航入口，支持按钮及 Cmd/Ctrl+K；仅匹配已加载到本账号界面的历史报告标题/问题和当前报告来源标题/URL/可用摘要。明确范围；不得宣称全文、全平台或联网搜索。输入只做本地筛选，不请求第三方、不存储查询、不暴露未加载的其他用户数据。提供空态与无匹配态，支持方向键、Enter、Escape 和可见焦点；快捷键不得干扰 IME、重复按键、其他原生弹窗或组合键。选择来源走既有出处定位，选择历史报告走既有路由。运行切换、退出登录及删除必须刷新或清除旧结果。
4. 点击报告引用后，出处定位清楚；提供明确“返回原句”动作，恢复原引用焦点与阅读位置。来源列表普通浏览、删除后的引用、连续核查不同引用、关闭抽屉、跨断点和报告切换均要安全处理；不能把焦点送到旧报告或已移除元素。桌面关闭出处和手机 Escape/关闭应按实际入口返回；不能在轮询更新时夺取用户焦点。
5. 动效用于说明开合、选择、状态变化：约 140–240ms 的 opacity/transform，避免 transition:all、无限循环和大面积模糊。尊重动态 reduced-motion，禁用移动与平滑滚动。原生对话框保留背景 inert、Escape 和焦点返回。交互目标至少 44px；正文至少 16px；浅/深模式及焦点状态可读。不得新增外部字体请求或新框架。

## 验收与边界

- 在隔离的合成账号/离线 provider 数据上，实际检查首页输入、登录、历史切换、读报告、点击引用、返回原句、来源/历史本地查找和退出登录；不使用真实私人研究作为公开 fixture，不访问 example.org 或付费 API。
- 测试本地检索范围及过滤、键盘选择和关闭、敏感结果清理、引用返回/报告切换/移动抽屉及 reduced-motion；执行相关客户端测试、typecheck、build、`scripts/check_design.py`，再按 CI 要求验收。桌面、390px 手机与断点附近检查溢出、遮挡、可见焦点。
- 与 [Linear 的界面改版](https://linear.app/now/behind-the-latest-design-refresh)、[早期改版](https://linear.app/now/how-we-redesigned-the-linear-ui)、[Notion 搜索](https://www.notion.com/help/search)、[Raycast 键盘操作](https://manual.raycast.com/keyboard-shortcuts) 对照的是任务入口、信息层级、上下文保留与键盘效率。没有同样本竞品测评，不宣称已经超过 Notion/Linear；报告本项目实际验证结果与剩余缺项。
- 本轮不解决尚未验证的联网 provider 覆盖、媒体转录、评论分页或第三方余额不足。界面应忠实显示已有状态。
