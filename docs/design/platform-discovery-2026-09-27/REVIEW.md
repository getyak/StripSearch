# 审查：平台发现与深度追踪

审查截面：2026-09-27。范围：本轮实施的探测引擎、导入解析、身份校正与帖子追踪；静态代码与离线测试复核，**未运行任何真实平台请求**。方法与判据同[技术设计](TECHNICAL.md)，来源见 [SOURCES](SOURCES.md)。

| 发现 | 级别 | 处置 |
|---|---|---|
| 账号枚举是双用途能力，maigret 生态有 stalkerware 争议 | P0 边界 | 只服务本人/已获授权/公开职业人物；创建任务必须声明 `authorization` 并随导出留痕；不做匿名揭露、位置/行踪、泄露库 |
| 用户名一致被误当身份（跨平台最常见的假阳性） | P0 | `exact_handle` 永不自动确认，只进 `needsReview` 并附理由；自动确认仅限确定性互链；测试固定该行为 |
| holehe 密码重置式探测可能违反站点 ToS、触发风控 | P1 | 不实现原生邮箱探测路径；邮箱轴只接受外部报告导入，探测合法性由运行者负责并写入限制 |
| holehe 为 GPL-3.0，与本仓库 Apache-2.0 不同许可 | P1 | 不 vendor 其代码、不子进程调用；只解析用户提供的 JSON 输出（数据）；导入格式按其 README 契约核实 |
| 导入报告把外部工具结论伪装成系统结论 | P1 | 每条导入结果带 `receipt`（工具/版本/时间/格式）与 `live_unverified` + `not_rechecked_by_stripsearch`；导出原样携带 |
| 403/429 被当成“账号不存在” | P1 | 状态机分开 `blocked` 与 `not_found`；测试固定；注册表对预期被拦平台（Reddit/X）显式标注 |
| 恢复邮箱/电话等再联系线索被存进证据库 | P1 | 解析即丢弃（`recontact_fields_dropped`），warning 留痕，导出断言不含该字段（测试固定） |
| 超时请求的费用被记成零 | P2 | `billing_outcome_unknown` + usage.`outcomeUnknown`；取消/超时后仍入账不发布 |
| 未验证规则被当已验证能力 | P2 | 逐规则 `verification` 标签随结果流转；除 GitHub（既有 adapter 验收）外全部 `live_unverified`；文档单列未验证清单 |
| 帖子正文全文入库引发第三方全文再分发问题 | P2 | 只存列表摘录（≤200 字符）+ 定位；`full_text_not_fetched` 恒定落下 |
| 同名人物资料被静默合并 | P2 | 链接逐平台显式状态 + 修订账（actor/basis/note/反证）；撤回/恢复对称留痕，不删除记录 |
| 探测流量可被滥用为批量枚举 | P2 | 每任务探测/请求/字节/帖子预算；每用户任务上限与启动限速；注册表限速字段；取消即时生效 |

## 已核验

- 共享契约、状态机、解析器、探测语义、校正与撤回级联：离线单测 27 项（`platform-discovery` / `discovery-adapters`）。
- 任务流程：9 组端到端（发现→待确认→校正→追踪→导出；撤回/恢复；取消+迟到守卫；重启续跑不重复计费；互链自动确认；导入；幂等；越权；校验）。
- 全量 Web 测试 187 项通过；冻结回放 40 案例 0 失败、0 网络调用；`scripts/check_design.py` 通过。
- maigret / holehe 输出格式按官方源码/README 核实（simple/ndjson 结构、状态词表、模块字典字段）。

## 未解决（实施门槛，本轮未编造通过）

1. **真实平台语义**：13 条规则里 12 条未经 live 验证；预期失败模式是降级 `unknown`，但命中率未知。
2. **真实工具端到端**：未运行 maigret/holehe CLI，报告导入只对合成报告验证。
3. **效果**：发现精度、归属错误率、人工负担全部未测（方案见 [EVAL](EVAL.md)）。
4. **合规**：各平台 ToS、探测流量合法性、GDPR/个保法下的处理依据需部署者逐场景复核；授权声明是产品约束不是法律意见。
5. **稳定性**：RSS/JSON 列表端点与标记串会漂移；需要版本化解析与失败监控。

## 2026-09-29 合并修复

- 合并当前 `main` 的 DSH 研究链路，bootstrap 同时保留 research 与 discovery 的注入、恢复和关闭逻辑。
- 读取响应时逐块限制大小，超限立即取消流；不先把完整响应装入内存。
- 种子页仅允许注册表 origin；成功 HTML 中的精确 `rel=me` 自链才支持自动归属。错误页、URL 前缀、普通提及、注释、脚本和 JSON 均不能自动确认；未知站点保留人工确认。
- 身份修订整批事务回滚；旧尝试完成不能移除新的运行任务，取消中的种子读取不能发布归属或帖子。
- 新增纯合成回归；所有 HTTP 响应由测试传输层提供，不访问示例域名或真实平台。此前 187 项是原分支截面，合并后的全量结果以本次 PR 检查记录为准。

结论：本轮把“用两个开源包真实查平台、一次纠正、深度追踪帖子”落成了**可运行、可撤回、可续跑、诚实标注**的执行层；它现在缺的是 live 验证与效果数据，在此之前不宣称发现能力。
