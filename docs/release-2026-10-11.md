# 2026-10-11 优化整合与发布边界

此次交付将此前独立完成的 Search / 第一阶段优化，与 `main` 的公开 GitHub Fetch 放入同一发布。发布通过独立审查、当前提交 CI、合并后部署和公网版本/持久化验收；当前进度与具体提交证据保留在关联 PR，线上版本读取 `/release.json`。

## 纳入的实现与分析

- [第一阶段设计](superpowers/specs/2026-10-05-search-first-step-design.md)与[实施计划](superpowers/plans/2026-10-05-search-first-step.md)：发现义务先冻结，按人物簇与账号展示原文依据，一次原子确认后才开展限定范围研究，刷新/重开保存选择草稿与发现历史。
- [Search Agent 细化](search-agent-refinement.md)：可审计模型决策、实际来源目录/正文窗口、已观察机构人物页线索、GitHub 原生组织类型与依赖复核；同名、第三方材料、本人关联及个人贡献分别核查。
- 身份与研究修复：可见作者语义、HTML/Markdown 引述边界、目标锚点、当前原文 hash/真实请求回执、撤回传播、核验输入重放绑定、五类研究问题与预算内补查；来源归属不因模型确信度升级。
- [标注驱动 harness 设计](annotation-harness-v2.md)、[深度契约](research-depth-contract.md)及已有阅读体验：原文查看、引用返回、局部检索、保护页面会话恢复和账号切换清理。设计不是尚未实施 runtime 的验收。
- 保留已合并的 [GitHub Fetch](fetch-integration.md)、[处理覆盖](fetch-coverage.md)与[本地恢复链](fetch-pipeline.md)。启动/路由/数据库初始化同时连接第一阶段与 GitHub Fetch，旧作业和来源历史不作破坏性迁移。

## 验收边界

离线验证使用合成资料与 fake/拒绝适配器，禁止抓取样例占位域名或调用付费研究 provider。生产镜像烟测继续禁网；线上验收核对前后端 SHA、资源、健康、登录、账号隔离、既有报告持久化和保护路由。

这次整合不主张 Figma 新稿像素对齐、真实模型人物判断质量、全平台持续历史、邮箱匹配、租约调度、CLI/MCP 交付或完整 Fetch 核验→补查→综合闭环。相应里程碑不会因 PR 合并而自动宣告完成。
